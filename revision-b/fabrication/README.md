# Revision B fabrication package

`V9958-Tester-RevB-B0-gerbers.zip` contains the final Gerber and separate plated
and non-plated Excellon drill files.

- Two layers, FR-4, 1.6 mm nominal thickness.
- 1 oz copper is suitable for the prototype.
- Minimum routed track 0.25 mm; minimum copper clearance 0.20 mm.
- Minimum copper-to-edge clearance 0.40 mm.
- Board size 170 x 118 mm.

Review the Gerbers and exact socket/header mechanical parts before ordering.
